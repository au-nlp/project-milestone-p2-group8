# Deep Multimodal Fusion for Clinical Trial Outcome Prediction

## Abstract
Clinical trial failure leads to immense financial and scientific costs, yet accurately identifying at-risk trials remains a challenge due to the severe class imbalance in public registries. Standard predictive models frequently succumb to the "accuracy paradox," maximizing global accuracy while failing to detect the minority failure class.

In this work, we propose a **Multimodal Fusion Architecture** utilizing an intermediate fusion strategy. We integrate structured metadata via a Multi-Layer Perceptron (MLP) with deep semantic text embeddings generated by `BioClinical-ModernBERT`. To address the critical imbalance (approx. 14% failure rate), we employ a random downsampling strategy on the training set. Our results demonstrate that this fusion approach recovers latent risk signals, achieving a **Failure Recall of 0.68** and outperforming unimodal baselines. While this sensitivity incurs a trade-off in precision, the model functions effectively as a robust, high-recall screening tool for proactive risk assessment.

## Introduction
Clinical trials represent the bottleneck of medical progress, consuming vast financial resources and years of operational effort [1]. While the aggregate failure rate of biomedical research is high, public trial registries are paradoxically dominated by completed studies [2], creating a severe class imbalance that obscures the signals of failure.

Traditional predictive approaches often rely on expert opinion or limited structured metadata (e.g., enrollment size), ignoring the rich semantic context hidden in trial protocols. Furthermore, standard machine learning models trained on this imbalanced data frequently succumb to the "accuracy paradox" [3], maximizing global accuracy by ignoring the minority failure class entirely.

**Our Solution:** We present a Deep Multimodal Fusion framework that learns from both the operational parameters (Structured Data) and the scientific design (Text Protocols) of a trial. By strictly managing data splits and balancing techniques, we move beyond misleading accuracy metrics to focus on **Failure Recall**—the ability to act as an early warning system for doomed trials.

## Novelty and Key Contributions
This project addresses the limitations of existing baselines (identified in our P2 milestone) by introducing a rigorous pipeline focused on risk detection.

*   **Intermediate Multimodal Fusion:** Unlike simple early fusion (concatenation), we propose a neural architecture that processes structured features and text embeddings in parallel branches before combining them. This allows the model to resolve conflicting signals, identifying trials that appear operationally robust (e.g., Phase 3, Industry Sponsor) but contain fatal protocol flaws hidden in the text.
*   **Strategic Imbalance Handling:** We demonstrate that standard training on this dataset yields a Failure Recall of 0.00 - 0.44. We implement a strategic **Random Downsampling** strategy on the training set, which proved essential for recovering the minority failure signal without introducing the synthetic noise associated with oversampling methods like SMOTE [4].
*   **Domain-Specific Embeddings:** We utilize **BioClinical-ModernBERT** to generate 1536-dimensional embeddings from trial protocols (`brief_summary` and `eligibility_criteria`), capturing domain-specific medical nuance that generic language models miss.

## Methods
Our pipeline consists of four distinct stages designed to prevent data leakage and maximize sensitivity.

*   **Data Preprocessing:** We process ~540,000 trials from the `louisbrulenaudet/clinical-trials` dataset. We select 7 structured features, apply Z-score normalization, and handle age outliers via Winsorization (capping at 120 years).
*   **Split Strategy:** Data is split 70/15/15 (Train/Val/Test) **before** any balancing occurs. This ensures our Test set reflects the real-world imbalance (~14% failure rate), preventing evaluation leakage.
*   **Feature Engineering:** Text embeddings were generated offline using `BioClinical-ModernBERT-base` on a GPU-accelerated pipeline. The resulting vectors were concatenated to form a dense semantic representation (1536 dimensions).
*   **Deep Learning Fusion:** We trained a PyTorch-based Multimodal Neural Network on the balanced data. The architecture features a **bottleneck design** in the text branch to compress the high-dimensional signal before fusion.

## Results
We evaluated our models based on **Failure Recall** (Sensitivity), as missing a failed trial is significantly more costly than a false alarm.

| Model | Recall (Failure) | Precision (Failure) | Accuracy |
| :--- | :---: | :---: | :---: |
| **1. Structured (Unbalanced)** | 0.44 | 0.87 | 0.91 |
| **2. Embeddings (Unbalanced)** | 0.00 | 0.00 | 0.86 |
| **3. Structured (Balanced)** | 0.66 | 0.46 | 0.84 |
| **4. Embeddings (Balanced)** | 0.65 | 0.24 | 0.66 |
| **5. Multimodal Fusion** | **0.68** | 0.25 | 0.67 |

**Key Findings:**
*   **Imbalance Hides Signal:** Model 2 (Unbalanced Embeddings) achieved 86% accuracy but **0.00 Recall**, proving that standard models ignore the minority class.
*   **Fusion Maximizes Sensitivity:** The Fusion model achieved the highest Recall (0.68), functioning as a high-sensitivity screening tool capable of flagging nearly 70% of potential failures.

## Project Data & Reproduction
*   **Original Source:** The raw dataset was sourced from the Hugging Face Hub: [`louisbrulenaudet/clinical-trials`](https://huggingface.co/datasets/louisbrulenaudet/clinical-trials).
*   **Important Note on Embeddings:** While the original dataset documentation mentions text embeddings, the distributed version **does not contain them**.
*   **Reproduction:** To reproduce the 1536-dimensional feature vectors used in our model, users must generate them manually. We have provided the necessary scripts in the `additional_scripts/` folder:
    1.  Run `embeddings_generation.ipynb` (requires GPU) to process the text fields via `BioClinical-ModernBERT`.
    2.  Run `combined.py` to merge the output shards into the final dataset.
